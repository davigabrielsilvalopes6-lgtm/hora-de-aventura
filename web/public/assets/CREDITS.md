## Versão para navegador

O mesmo GLB é carregado pelo Three.js, preservando seus 374 meshes e a geometria original. Escala visual 100×, emissão desativada, materiais não metálicos e iluminação adaptada. As plataformas de serviço e interiores simplificados são adaptações para esta versão. O modo leve usa uma representação própria, identificada como tal; não é o GLB original.
